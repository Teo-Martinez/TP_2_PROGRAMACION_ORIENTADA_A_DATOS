La simulación está permitida por la consigna; Open Food Facts no es obligatorio.
Los datos ficticios no se presentan como fiables para estudiar productos reales.
La fiabilidad evaluable aquí es la del procedimiento y su adecuación a probar
las funciones del programa. No hay proveedor externo ni condiciones de acceso.

De la rúbrica adjunta se aplican diagnóstico previo, reglas justificadas,
trazabilidad, cifras antes/después, interpretación limitada y pruebas reproducibles.
No se trasladan R, SQLite, JOIN, transacciones de base de datos, notebook en Colab
ni gráficos obligatorios: corresponden al otro trabajo. La consigna de Python
admite una tabla como resultado. El README se limita a ejecución por indicación
del profesor y enlaza toda la documentación complementaria.

La revisión técnica no garantiza calificación: resta publicar, conceder acceso,
entregar enlace con commit y defender decisiones propias según reglas de cátedra.
